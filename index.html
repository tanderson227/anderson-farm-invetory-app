Data Safety & Web Dev Guide

Will I lose my data when I update the code on GitHub?

No! You will NOT lose your data. Here is why:

This app stores your inventory items directly inside your web browser's localStorage.

  • Code vs. Storage: GitHub Pages hosts the application code file (index.html). Your inventory data lives safely inside your family phone or laptop browsers under your site's domain.
  • When you edit & re-upload: When you add new features or modify colors in index.html and push it to GitHub, the browser downloads the new visual app layout, but reads the existing saved inventory items from `localStorage` unharmed!
  • Best Practice Safety Net: Before pushing major new updates, click "Backup / Export" to download a .json backup file as an extra precaution.

How This Single-File App Operates

This entire app combines three core web technologies inside one file:

HTML

Structure & elements: Headers, modals, dynamic tab buttons, and inventory card templates.

Tailwind CSS

Styles & colors: Custom terracotta red, farm green, responsive grid layouts, and font styling.

JavaScript

Brain & logic: Calculates total valuation $, filters low stock, adds custom tabs, & saves to `localStorage`.

Adding to Family Phones as a Full-Screen App

iPhone / iPad (Safari)

Open your GitHub Pages URL in Safari → Tap Share Icon (box with arrow) → Tap "Add to Home Screen".

Android (Chrome)

Open your URL in Chrome → Tap the 3 dots menu in top right → Tap "Install App" or "Add to Home screen".
