Anderson Farm App Guide

1. Real-Time Multi-Device Sync

All family members sharing this web app automatically view and edit the exact same live inventory node. Edits made on one phone update everyone's screen in real time.

2. Adding to Mobile Home Screen (PWA)

Open this page in Safari (iOS) or Chrome (Android) and tap "Add to Home Screen". The app will launch as a full-screen application without standard web browser bars.

3. Safe Environment Routing

When running on the official GitHub Pages link, the pill in the header displays 🟢 Live Cloud Sync. When testing on your computer or dev branch, it automatically routes to 🟢 Test Mode to keep active records safe.

4. Managing Custom Equipment & Categories

Tap "+ Manage Tabs & Backups" to create custom tabs for individual tractors, implements, or farm fields.

5. Offline Caching & Backups

If signal is lost while working in remote sheds, edits are held safely in local memory and automatically pushed to the cloud once internet re-connects. Use the JSON/CSV tools to save physical copies.
