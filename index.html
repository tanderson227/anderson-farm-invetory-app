Cloud Sync & App Installation Guide

How Real-Time Cloud Syncing Works

Your app is connected to Google Firebase Realtime Database.

  • Zero Latency: When anyone updates a quantity or adds a new hybrid in the field, all family phones update instantly without needing to refresh.
  • Offline Fallback: If you enter a barn with no cellular service, changes are cached locally in your browser and pushed to the cloud automatically once you reconnect.

Will GitHub updates erase inventory?

No! GitHub Pages only holds the visual code. Your inventory items live securely inside your Firebase cloud database.
